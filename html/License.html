  * Hardware Revision String (UUID 0x2A27, m_hardwareRevChrUuid)
  * Software Revision String (UUID 0x2A28, m_softwareRevChrUuid)

  setSerialNumber(), setFirmwareRev(), setHardwareRev(), setSoftwareRev().
